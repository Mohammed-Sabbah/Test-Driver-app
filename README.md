# زمام - معمل تشخيص شبكة الهاتف للسائق (Zemam Cellular Lab)

مختبر هندسي معزول ومحكم المتغيرات لفحص وتشخيص أداء واستقرار تطبيق السائق الميداني (Driver PWA) عبر **بيانات الهاتف الخلوي (4G / 5G / LTE)** بدون الحاجة إلى شبكة Wi-Fi.

---

## 🎯 الهدف الهندسي
في التطبيق الأساسي لمنظومة زمام، تتداخل متغيرات كثيرة (سيرفر Express منفصل، شهادات SSL ذاتية، Socket.io، كوكيز المصادقة، والعديد من الريكويستات المتزامنة).
تم بناء هذا المعمل المستقل لعزل المشاكل واختبار تدفق البيانات الحقيقي لنبضات الـ GPS في ظل ظروف الأبراج الخلوية:
- حجب المنافذ غير القياسية من قبل شركات الاتصالات.
- سقوط اتصالات الـ TCP / WebSockets الخاملة أثناء حركة المركبة وتبديل الأبراج (Cellular Handoffs).
- فحص استقرار بروتوكول HTTP POST المباشر كبديل موثوق لنقل التيليماتري.
- اختبار مرونة التخزين المحلي (IndexedDB) والمزامنة بالدفعات (Batch Sync).

---

## 🔬 مصفوفة الفحص (Test Matrix)

### 1. طرق الإرسال المتاحة للتبديل الفوري:
1. **`REST (POST)`**: إرسال كل نبضة موقع مؤهلة كريكويست HTTP خفيف ومستقل فور توليدها، مع قياس زمن الاستجابة (Latency) وتأخير النقل (Transit Delay).
2. **`Batch (IndexedDB)`**: تجميع النبضات محلياً في IndexedDB وإرسالها كدفعة واحدة عند اكتمال 5 نقاط أو عند عودة الاتصال.
3. **`Stream (SSE)`**: فتح قناة تدفق مستمرة لفحص قدرة شبكة الجوال على إبقاء الاتصال مفتوحاً دون إغلاقه قسرياً.

### 2. الفلاتر واللوجيك المطابق لتطبيق زمام:
- **فلتر الدقة (GPS Drift Filter)**: استبعاد القراءات التي تزيد دقتها عن ±35 متر لتجنب تشتت المسار.
- **فلتر القفزات المستحيلة**: استبعاد القفزات اللحظية الناتجة عن تغيير برج الاتصال (> 180 كم/ساعة).
- **قفل الشاشة التلقائي**: تفعيل `navigator.wakeLock` لمنع إطفاء الشاشة وتوقف قراءات الـ GPS أثناء القيادة.
- **طابور الطوارئ**: تحويل النبضات تلقائياً إلى IndexedDB فور تعثر أي ريكويست وإعادة المحاولة عند عودة الشبكة.

## 🚀 النشر على Vercel

المشروع مصمم ليعمل بالكامل داخل **Next.js (App Router)** موحد الواجهة والباك إند بدون الحاجة إلى خادم منفصل:

1. ارفع هذا المستودع إلى GitHub:
   ```bash
   git add .
   git commit -m "feat: initial commit for cellular diagnostic lab"
   git remote add origin https://github.com/<YOUR_USER>/zemam-cellular-lab.git
   git push -u origin main
   ```
2. اربط المستودع في منصة **Vercel** واضغط **Deploy**.
3. ستحصل على رابط HTTPS عالمي معتمد يعمل بكفاءة تامة على متصفحات الهواتف وبيانات الـ 4G/5G.
